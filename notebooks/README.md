# Notebook Workfile

\`predictor.ipynb\` is the original notebook supplied for this project. It is preserved byte-for-byte as a workfile; it is not presented as a fully refactored production pipeline.

For the reproducible, tested workflow, use \`src/price_range/\` and the commands in the root README. The package implementation corrects multiclass ROC-AUC evaluation by using the one-vs-rest strategy with the full probability matrix.
